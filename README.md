# Trip Report Notes

Fills in one person's section of a Word trip report from a phone. Notes are kept on the device and exported as .docx or plain text. Missions can also be created without a template, and a summary board can be exported as .pptx.

Site: https://dassey.github.io/Trip-Report-Notes/

Credits: [JSZip](https://github.com/Stuk/jszip) by Stuart Knightley (MIT), which bundles [pako](https://github.com/nodeca/pako) (MIT).
